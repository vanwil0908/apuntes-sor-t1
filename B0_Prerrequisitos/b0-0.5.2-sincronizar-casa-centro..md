## 🤔 Respuestas a las preguntas

1. ¿Por qué NO se mete la bóveda en OneDrive si usamos Git?
Porque ambos son sincronizadores peleándose por los mismos ficheros. Git guarda su historial en la carpeta delicada .git y OneDrive la sincroniza a medias corrompiéndola; además, OneDrive crea copias en conflicto (como fichero-MiPC.md) que ensucian el directorio y hace que el comando git pull pierda sentido. Por ello, la bóveda debe estar en local fuera de OneDrive en ambos equipos, usando GitHub como nube.

2. Escribe el ciclo diario de tres pasos.
- Llego a un ordenador: ejecuto git pull para bajar lo último del otro equipo.
- Trabajo en Obsidian: edito o creo entradas.
- Antes de irme: ejecuto git add, git commit y git push.

3. ¿Qué problema puede aparecer si olvidas el pull al empezar?
Puede aparecer un conflicto (CONFLICT) porque editaste el mismo fichero en dos sitios distintos sin hacer pull antes, provocando que Git no sepa qué versión es la que vale. Si aparece la palabra CONFLICT, se debe parar y preguntar al profesor.
