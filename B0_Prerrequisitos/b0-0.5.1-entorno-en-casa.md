## 🎯 Qué se pedía

Instalar en el ordenador de casa las herramientas Obsidian, Git y OBS, generar una clave SSH exclusiva para el equipo de casa y añadirla a GitHub, y reconstruir la bóveda local (fuera de OneDrive) clonando los cuatro repositorios desde GitHub para dejar el equipo de casa en el mismo estado que el del centro.

## ⌨️ Comandos y pasos importantes

`sudo apt install git` — instala Git en Linux (en Windows se descarga desde `git-scm.com`)

`git --version` — comprueba que Git está instalado correctamente.

`ssh-keygen -t ed25519 -C "tu-correo-de-github"` — genera la nueva clave SSH del equipo de casa.

`cat ~/.ssh/id_ed25519.pub` — muestra la clave pública en pantalla para poder copiarla y añadirla a GitHub

`git config --global user.name "Tu Nombre"` — configura tu nombre global en Git.

`git config --global user.email "tu-correo-de-github"` — configura tu correo electrónico global en Git.

`ssh -T git@github.com` — verifica la autenticación SSH con GitHub comprobando que responde con `Hi TU-USUARIO!`

`git config --global --list` — comprueba la configuración global de Git (usado si hay que deshacer la configuración para repetir el paso).

`mkdir -p RUTA_SOR/Boveda_SOR/00_Apuntes` — crea la carpeta local para los apuntes

`mkdir -p RUTA_SOR/Boveda_SOR/01_Practicas` — crea la carpeta local para las prácticas.

`cd RUTA_SOR/Boveda_SOR/00_Apuntes` — accede a la carpeta de apuntes.

`pwd` — comprueba que estás ubicado en la ruta correcta antes de clonar.

`git clone git@github.com:TU-USUARIO/apuntes-sor-t1.git Trimestre_1` — clona tu repositorio de apuntes renombrando la carpeta a `Trimestre_1`.

`cd RUTA_SOR/Boveda_SOR/01_Practicas` — accede a la carpeta de prácticas.

## 🤔 Respuestas a las preguntas

1. ¿Por qué clonas desde GitHub en vez de copiar con pendrive?
Porque en GitHub es donde está subida la versión buena desde el centro; al clonar directamente desde GitHub nos aseguramos de que la copia de casa sea idéntica a la del centro

2. ¿Por qué generas una clave SSH nueva en casa?
Porque la clave privada no se copia nunca de un equipo a otro; en casa se genera una clave nueva y se añade a GitHub junto a la del centro.

3. ¿Dónde NO debe estar la bóveda?
No debe estar dentro de OneDrive (ni en ninguna carpeta sincronizada que muestre el icono de nube, como Documentos si está sincronizado), ya que Git y OneDrive se pelean; debe ir en una carpeta local fuera de OneDrive.
