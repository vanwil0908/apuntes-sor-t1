## ⌨️ Comandos y pasos importantes

- `pwd` — Muestra la ruta actual del directorio para verificar que estás situado exactamente dentro de la carpeta `Trimestre_1` antes de inicializar Git.
    
- `git init` — Convierte la carpeta actual en un repositorio de Git local.
    
- `git branch -M main` — Establece o renombra la rama principal del repositorio como `main`.
    
- `git status` — Comprueba el estado actual del repositorio, mostrando los archivos modificados o pendientes de rastrear.
    
- `git remote add origin <url>` — Conecta tu repositorio local con la dirección del repositorio remoto creado en GitHub.
    
- `git add <fichero>` — Añade ficheros específicos al área de preparación (`staging area`) para incluirlos en el siguiente guardado.
    
- `git commit -m "mensaje"` — Guarda de forma permanente una instantánea ("foto") de los cambios preparados junto a un mensaje descriptivo.
    
- `git push -u origin main` — Sube los commits locales almacenados hacia el repositorio remoto en GitHub por primera vez.

## 🤔 Respuestas a las preguntas

1. ¿Por qué un repositorio por trimestre?
Al cerrar cada trimestre, el repositorio queda "congelado" y se califica limpio, constituye un enlace claro que se pasa una vez, y si algo se lía en uno, no afecta a los demás.

lleva la fecha cuando las de fase no la llevan? (La convención está en el Bloque 0 · Fase 0.1.b.)
Las entradas normales de fase siguen la convención `material-CODIGO-titulo-corto.md` sin fecha porque el código ya las ordena.
