## 🤔 Respuestas a las preguntas

1. ¿Qué hace Use this template ? Después de pulsarlo, ¿sobre qué repositorio trabajas, el mío o el tuyo?
Use this template nos permite utilizar un repositorio de otra persona, generando un nuevo repositorio completamente independiente en nuestra cuenta. 
El repositorio en el que estaríamos trabajando sería al mío.

2. Te has bajado el Bloque 1 por HTTPS y no te ha pedido contraseña. ¿Por qué? ¿Cuándo sí te la habría pedido?
No nos ha pedido la contraseña porque es un repositorio público, la contraseña se nos pedirá cuando sea un repositorio privado.

3. En el Explorador, la carpeta del ZIP y la carpeta clonada se ven idénticas. ¿Qué tiene una que no tiene la otra, y
 qué tres cosas dejas de poder hacer sin ella?
 La carpeta clonada mediante Git incluye una carpeta oculta llamada .git y la carpeta descomprimida del ZIP no la contiene.
 Las 3 cosas que dejarían de funcionar son los commits, el git push y pull y gestionar las ramas e historial.
 
4. Anotas una duda en un fichero de la práctica, en el ordenador del aula. ¿Qué tienes que hacer para encontrar
el sábado en casa?
Si hemos hecho anteriormente el push, se debe de hacer el pull.
